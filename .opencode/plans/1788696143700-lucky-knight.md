1. **Lister les branches a supprimer** (read-only)
   - `git branch --merged main` : branches locales fusionnees, exclure `main`.
   - `git branch -r --merged main` : branches distantes fusionnees, exclure `main`, `origin/HEAD`, `origin/main`.

2. **Supprimer les branches locales fusionnees**
   - `git branch -d <branches>` (lowercase `-d` : refuse toute branche non fusionnee, securitaire).

3. **Supprimer les branches distantes fusionnees, remote par remote**
   - `git push github --delete <branch>` pour chaque branche fusionnee.
   - `git push gitlab --delete <branch>` pour chaque branche fusionnee.
   - **Ne PAS utiliser `origin`** : il a 3 push URLs, on ne touche pas a `notabug` (pas de CI).
